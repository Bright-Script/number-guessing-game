# Number Guessing Game 🎯

A simple command-line Number Guessing Game built with Python.

The computer randomly selects a number between **1 and 100**, and the player has to guess the correct number within a limited number of attempts. The game offers three difficulty levels, each with a different number of chances.

## Project URL

This project is part of the roadmap.sh beginner projects:

[Number Guessing Game – roadmap.sh](https://roadmap.sh/projects/number-guessing-game)

## Features

- Random number generation between 1 and 100.
- Three difficulty levels:
  - **Easy:** 10 attempts.
  - **Medium:** 5 attempts.
  - **Hard:** 3 attempts.
- Input validation to handle non-numeric entries.
- Hints to help players determine whether their guess is too high or too low.
- Option to play multiple rounds.

## Requirements

- Python 3.x
- A terminal or command-line interface.

No external libraries are required. The project uses Python's built-in `random` module.

## How to Run the Project

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone <your-repository-url>
```

### 2. Navigate to the Project Directory

```bash
cd number-guessing-game
```

### 3. Run the Game

Execute the Python file using:

```bash
python main.py
```

If your system uses `python3`, run:

```bash
python3 main.py
```

## How to Play

1. Start the game using the command above.
2. Choose a difficulty level:
   - Enter `1` for Easy.
   - Enter `2` for Medium.
   - Enter `3` for Hard.
3. Enter a number between 1 and 100.
4. Follow the hints:
   - The game tells you whether your guess is too high or too low.
5. Try to guess the correct number before running out of attempts.
6. After the round, choose whether you want to play again.
